05GOOD TO KNOW

気になること、
ここで解決。

詳しい使い方はGitHubへ

見出しや太字などは、ツールバー・メニュー・右クリック・ショートカットで付けられます。記法を調べずに、仕上がりの見た目のまま書けるエディタです。

Windows 11（64ビット）用です。Mac・スマートフォン向けの配布版はありません。

無料で利用できます。無保証です。オープンソースではありません。利用条件の全文は配布ZIP内の「利用規約.txt」をご覧ください。

コード署名をしていないため、初回起動時にSmartScreenが表示されることがあります。配布元を確認のうえ、READMEの画面付き手順をご確認ください。

利用状況の送信や更新確認などの通信はしません。ただし、文書内のhttps画像は表示のために読み込みます。この読み込みは設定で切れます。

bunzo.exeと同じフォルダに作られます。利用をやめる場合はフォルダごと削除できます。ファイルの関連付けを登録している場合は、先に設定画面で解除してください。
