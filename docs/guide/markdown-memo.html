Markdownでメモを作成する

いつものメモが、そのまま読みやすい文書になる。

とりあえず書いたメモも、見出しや箇条書きで整えると、あとから読み返しやすくなります。筆屋文蔵なら、テキストを書く気軽さで、手順書や議事メモのような形にまとめられます。

まず書いてみるメモの仕上がり例使い方のバリエーション

書く → 少し整える → 保存する

  1. 新しい文書を開く。 筆屋文蔵を起動するか、Ctrl+N で新規ウィンドウを開きます。
  2. まず内容を書く。 思いついたことを普通の文章で入力します。Enter で段落を分けられます。
  3. 見出しとリストで整える。 タイトルの行で［見出し 1］、話題ごとの行で［見出し 2］を選びます。項目を並べるときは［箇条書き］を使います。
  4. 名前を付けて保存する。 Ctrl+S を押し、打ち合わせメモ.md などの名前で保存します。
書き始めたら、早めに一度保存一度も保存していない新規文書は自動バックアップの対象外です。最初に名前を付け、その後も Ctrl+S で保存する習慣を付けておくと安心です。

使い方整え方のヒント

書いたメモを、次の文書の土台に

残した .md ファイルは、後日開いて追記できます。簡単な覚え書きから始めて、内容がまとまったら説明や表を足し、手順書や共有用の資料へ育てていけます。

画像を含むメモを渡すときは、MDファイルと画像フォルダを一緒に渡してください。受け取る側のMarkdownアプリによって、表示に違いが出る場合があります。
