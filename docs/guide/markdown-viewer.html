無料Markdownビューアとして使う

書くためだけでなく、読むためにも。

既存のMDファイルを読むだけなら、筆屋文蔵をMarkdownビューアとして使えます。コード編集用の画面を開かず、見出し・箇条書き・表が整った文書として内容に目を通せます。

便利な場面読むための使い方読むときのポイント

こんな文書を読むときに便利です

文書見やすくなるポイント
README・使い方見出しで構成をつかみ、手順や注意点を追いやすくなります。
作業手順書・チェックリスト番号リストやタスクを、文章のまとまりとして確認できます。
AIが作成したMDファイル説明、箇条書き、比較表を整った表示で読めます。
自分で残したメモ過去の記録を開き、要点を拾って読み返せます。

「Markdownの記号を眺めるより、文書として読みたい」という場面に向いています。筆屋文蔵は無料で利用できます。

読むための使い方

  1. Ctrl+O でMDファイルを開きます。関連付けを設定しておけば、ダブルクリックで開けます。
  2. 本文を読みます。ツールバーが不要なら［表示］→［ツールバー］で隠せます。
  3. ［ファイル］→［設定］で書体・文字の大きさ・行間を、自分が読みやすい値にします。
  4. 探したい項目があれば Ctrl+F。リンクを開くときは Ctrl+クリック を使います。

複数の文書は別々のウィンドウで開けます。手順書を読みながら別のメモを確認する、といった使い方もできます。

読むときに知っておきたいこと

必要なときには、そのまま編集できます

ビューアとして使っていても、通常は編集できる状態です。誤って入力した場合は Ctrl+Z で戻せます。保存せず閉じるときに確認が出たら、残したい変更かどうかを確認してください。文書の内容は保存するまで元のファイルに反映されません。

画像は、文書とは別のファイルです

文書内で参照する画像の場所が変わると表示できなくなります。ローカルの文書は、画像フォルダも一緒に受け取ってください。外部画像の読み込みは［設定］で切り替えられます。

Markdownの記法そのものを見たいときは

Ctrl+/ でソース表示に切り替えます。通常表示とソース表示を行き来して、元の記法も確認できます。

筆屋文蔵での表示は、他のMarkdownサービスと完全に同じとは限りません。公開先固有の記法や表示がある文書は、必要に応じて公開先でも確認してください。
