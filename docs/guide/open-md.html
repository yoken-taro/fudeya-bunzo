MDファイルの開き方

「この .md ファイル、どうやって読むの？」

README、作業手順、AIが作った文書。MDファイルは、文章に見出しやリストの記号を付けたテキストファイルです。筆屋文蔵なら、見出しや表が整った表示で読めて、そのまま編集もできます。

まず開いてみるダブルクリックで開く読むときのヒント

まずは、ファイルを選んで開く

  1. 筆屋文蔵の bunzo.exe を起動します。
  2. ［ファイル］→［開く］、または Ctrl+O を押します。
  3. 読みたい .md / .markdown ファイルを選びます。

エクスプローラーから筆屋文蔵のウィンドウへ、ファイルをドラッグ＆ドロップしても開けます。まず一度試すなら、この方法が手軽です。

アプリがまだない場合は、最新リリースの Windows 用ZIPをダウンロードし、展開して起動してください。使い始める手順もご覧ください。

いつも読むなら、ダブルクリックで開く

MDファイルを筆屋文蔵に関連付けておけば、ファイルをダブルクリックするだけで開けます。「文書を読むためにアプリを起動して、ファイルを探す」という手間を減らせます。

  1. 筆屋文蔵を、今後も使う場所に置きます。
  2. ［ファイル］→［設定］を開き、［関連付け］の［登録］を押します。
  3. Windows側の「プログラムから開く」や既定のアプリの設定で、MDファイルを開くアプリとして筆屋文蔵を選びます。候補に出ない場合は、展開先の bunzo.exe を指定します。
  4. MDファイルをダブルクリックして、筆屋文蔵で開くことを確認します。
［登録］だけでは、既定のアプリは変わりません筆屋文蔵の［登録］は、Windowsに「このアプリでMDファイルを開ける」と知らせる操作です。いつも使うアプリにする設定は、Windows側で選びます。設定画面の［登録］は［OK］を待たず、その場で実行されます。

アプリの場所を変える前や削除する前には、［関連付け］の［解除］を行ってください。別の場所に置き直した場合は、移動先で登録し直します。

開いた後は、見やすく読む

  • 見出しで文書のまとまりを追い、表はセルの並びで確認できます。
  • 長い文書は Ctrl+F で必要な言葉を検索します。
  • リンク先は Ctrl を押しながらクリックすると開けます。
  • 読みやすい文字の大きさや行間は、［ファイル］→［設定］で調整できます。

文字化けする場合は、［ファイル］→［文字コードを指定して開き直す］で作成元の文字コードを選びます。画像が見えない場合は、MDファイルと画像フォルダが一緒に置かれているか確認してください。

読むだけの使い方は、無料Markdownビューアとして使うで紹介しています。
