01使い始める

  1. 最新リリースのページを開き、Assets にある Windows 用の ZIP をダウンロードします。
  2. ZIPを右クリックし、［すべて展開］で、書き込みのできるフォルダに展開します。
  3. 展開したフォルダの bunzo.exe をダブルクリックします。インストールは不要です。
  4. 文章を入力し、Ctrl + S で名前を付けて保存します。

対応環境は Windows 11（64ビット）です。配布ZIP内の利用規約もご確認ください。

初回起動時に確認画面が出たら「WindowsによってPCが保護されました」と表示されることがあります。配布元を確認のうえ、READMEの画面付き手順をご確認ください。

02画面の見方

  • タイトルには開いているファイル名が表示されます。変更してまだ保存していない文書には、その印が付きます。
  • メニュー・ツールバーから保存、書式の変更、表や画像の挿入などを選びます。幅が足りないときは、ツールバーの［≫］から残りのボタンを使えます。
  • 編集領域では、文章を見た目のまま編集します。カーソルのある場所では、Markdownの記号が表示されることがあります。
  • ステータスバーでは文字数、文字コード、改行コードを確認できます。文字を選ぶと選択範囲の文字数も表示されます。

ツールバーは［表示］→［ツールバー］で表示・非表示を切り替えられます。

03開く・保存する

ファイルの基本操作
やりたいこと操作
新しい文書を書く［ファイル］→［新規ウィンドウ］（Ctrl+N）。別のウィンドウが開きます。
文書を開く［ファイル］→［開く］（Ctrl+O）。Markdown（.md / .markdown）やテキストファイルを選びます。ファイルをウィンドウにドラッグ＆ドロップしても開けます。
保存する［ファイル］→［上書き保存］（Ctrl+S）。新規文書では保存先と名前を選びます。
別の名前で保存する［ファイル］→［名前を付けて保存］（Ctrl+Shift+S）。
ウィンドウを閉じる［ファイル］→［閉じる］（Ctrl+W）。未保存の変更があれば、保存するか確認されます。

新規で何も入力していないウィンドウでは、そのまま文書を開きます。それ以外は新しいウィンドウで開くので、今の文書を残して作業できます。

文字コードと改行コード

新規文書は UTF-8（BOMなし）で保存されます。既存の文書は、読み込んだ文字コードや改行コードを引き継ぎます。改行コードが混在している文書は、保存時に統一する種類を選びます。

文字化けして見える場合は、［ファイル］→［文字コードを指定して開き直す］から UTF-8 / UTF-16 LE / UTF-16 BE / Shift_JIS を選びます。画面下の文字コード表示をクリックしても選べます。

読み取り専用の文書読み取り専用の表示がある場合は編集できません。［名前を付けて保存］で書き込みのできる場所に保存すると、編集できるようになります。

04文章を書く・整える

段落と改行

普通の文章で Enter を押すと、新しい段落になります。同じ段落の中で行を変えたいときは Shift+Enter を使います。

見出しを付ける

  1. 見出しにしたい行にカーソルを置きます。
  2. ツールバーの［本文 ▾］から［見出し 1］〜［見出し 6］を選びます。［書式］メニューからも選べます。
  3. 通常の文章に戻すには［本文］を選びます。

見出しは Ctrl+1 〜 Ctrl+6、本文は Ctrl+0 でも指定できます。

太字・斜体・取消線・文中コード

装飾したい文字を選んでから、ツールバーや［書式］メニューの項目を選びます。すでに装飾された文字の中にカーソルを置いて同じ操作をすると、その装飾を解除できます。

文字を選んでいないときなど、現在の場所で使えないボタンは灰色になります。太字などを付けるときは、まず対象の文字を選んでください。

箇条書き・番号リスト・タスク

  • 行にカーソルを置き、［箇条書き］［番号リスト］［タスク］を選びます。
  • Enter で次の項目が作られます。空の項目で Enter を押すと、リストを抜けます。入れ子の場合は1段浅くなります。
  • Tab で項目を1段深くし、Shift+Tab で1段浅くします。
  • タスクはチェックボックスをクリックして完了・未完了を切り替えます。

引用・水平線

引用にしたい行で［引用］を選びます。引用内では Enter で引用を続け、空の引用行で Enter を押すと抜けられます。区切りを入れたい場所では［挿入］→［水平線］を選びます。

操作を取り消す

Ctrl+Z で元に戻し、Ctrl+Y でやり直せます。

05表を編集する

表を作る

  1. 表を入れたい場所にカーソルを置き、ツールバーの［表 ▾］を押します。
  2. マス目で大きさを選びます。数字で指定する場合は、［挿入］→［表］（Ctrl+T）を選びます。
  3. 「列の数」と「行の数（見出しを含む）」を入力し、［挿入］を押します。各1〜99を指定できます。
  4. セルをクリックして内容を入力します。一番上の行は見出し行です。
表の中で使うキー
キー動き
Tab / Shift+Tab次 / 前のセルへ移動します。最後のセルで Tab を押すと行を追加します。
Enter下のセルへ移動します。最後の行では行を追加します。
Shift+Enterセルの中で改行します。「HTMLタグを使う」が有効な場合は、改行が <br> として保存されます。無効の場合は空白になります。
Escセルの編集を抜けます。

行・列の追加、削除、文字の揃え方

対象のセルを右クリックして、［行を上に追加］［行を下に追加］［列を左に追加］［列を右に追加］、［左揃え］［中央揃え］［右揃え］などを選びます。表の操作バーからも操作できます。

見出し行と最後の1列は削除できません。表全体を消す場合は［表を削除］を選びます。

06コピーと貼り付け

  • Excelのセル範囲をコピーして本文に Ctrl+V で貼り付けると、Markdownの表に変換されます。
  • WordやWebページからは、見出し・リスト・表などをMarkdownに変換して貼り付けます。元のレイアウトや装飾をすべて再現するわけではありません。
  • 文字だけを貼りたいときは Ctrl+Shift+V（プレーンテキストとして貼り付け）を使います。
  • スクリーンショットなどの画像も Ctrl+V で貼り付けられます。保存先については「画像を入れる」をご覧ください。

コードブロックや文中コードなどの中では、書式を変換せず文字として貼り付けます。

07リンクを入れる

  1. リンクにしたい文字を選び、［リンク］（Ctrl+K）を押します。文字を選ばずに開くこともできます。
  2. ［表示する文字］と［リンク先（URL）］を入力して［挿入］を押します。

文字を選んだ状態でURLを貼り付ける方法でも、リンクを作れます。

リンクを開く・変更する

Ctrl を押しながらリンクをクリックすると開きます。右クリックの［リンクを開く］も使えます。

リンク先を変えるには、リンクの中にカーソルを置いて Ctrl+K、または右クリック→［リンクを編集］を選びます。表示する文字そのものは本文で編集します。

08画像を入れる

パソコンの画像・スクリーンショットを入れる

［挿入］→［画像］（Ctrl+Shift+I）でファイルを選ぶか、画像ファイルをドラッグ＆ドロップします。クリップボードの画像は Ctrl+V で貼り付けられます。

画像は文書と同じ場所にある images フォルダ（設定で変更できます）へコピーされます。初めて必要になったときは、フォルダを作成するか確認されます。まだ保存していない文書では一時的に保持し、文書を初めて保存するときに保存先へ移します。

文書を移動・共有するときMarkdownファイルと画像フォルダを一緒に移動してください。画像の説明文だけが文書に含まれ、画像ファイル自体は別に保存されています。

画像の右クリックメニュー

  • ［画像を差し替え］で別の画像に変えます。
  • ［画像の説明（alt）を編集］で、画像の説明文を入力します。
  • ［元の場所を参照］や［URL を参照］で、コピーせずに別の場所の画像を参照できます。
  • 参照中の画像を文書と一緒に保管したいときは［このフォルダにコピー］を使います。
  • ローカル画像では［ファイルの場所を開く］で保存場所を確認できます。

Web上の画像

Webの画像はURL参照として貼り付けられる場合があります。外部画像の読み込みを止めたいときは、［設定］の［外部（https）の画像を表示する］をオフにします。

画像の挿入を元に戻しても、コピー済みの画像ファイルは自動削除されません。

09コードとソース表示

コードブロックを入れる

［挿入］→［コードブロック］（Ctrl+Shift+K）でコードを書く領域を入れます。ブロック右上の言語の選択から、表示する言語を指定できます。短い語句をコードにする場合は、その文字を選んで［文中コード］を使います。

Markdownの記号を直接編集する

［表示］→［ソース表示］（Ctrl+/）で、Markdownの記号を含む表示に切り替えます。同じ操作で元に戻ります。表や書式の記法を直接確認・修正したいときに使えます。

たとえば、次のような文字で見出しやリストが表現されています。

# 今日のメモ

## やること

- 原稿を書く
- 内容を確認する

**大切なこと**を太字にする。

保存されるのはMarkdownのテキストです。通常表示とソース表示で、別々のファイルになることはありません。

10検索・置換する

  1. Ctrl+F で検索バーを開き、探したい文字を入力します。
  2. Enter で次、Shift+Enter で前の一致箇所へ移動します。［↑］［↓］も使えます。
  3. 閉じるときは Esc または［×］を押します。

文字を置き換える

Ctrl+H で置換欄も開きます。検索する文字と置き換える文字を入力し、［置換］または［すべて置換］を押します。読み取り専用の文書では置換できません。

［大文字と小文字を区別］と［正規表現］で検索方法を変えられます。普通に文字を探すときは［正規表現］をオフにして使ってください。

11設定を変える

［ファイル］→［設定］を開きます。通常の設定は［OK］で反映し、［キャンセル］で取り消します。

設定できること
項目内容
表示本文の書体、文字の大きさ（12〜32px）、行間（1.2〜2.5）を変更します。既定は BIZ UDPゴシック、16px、行間1.8です。
画像画像を保存するフォルダの名前と、外部（https）画像を表示するかを指定します。既定のフォルダ名は images です。
書き方［HTMLタグを使う］と、新規文書の改行コード（LF / CRLF）を選びます。HTMLタグの設定は、表のセル内改行の保存方法などに影響します。
自動バックアップ有効・無効、入力が止まってからの秒数、書き出す間隔、バックアップを残す日数を設定します。
関連付けMarkdownファイルを筆屋文蔵で開くための登録・解除を行います。この［登録］［解除］は［OK］を待たず、その場で実行されます。

アプリを移動したり削除したりする場合は、先に関連付けを解除してください。

12バックアップと復元

自動バックアップは、保存済みの文書に加えた未保存の変更を、異常終了に備えて別に記録する機能です。既定では入力が2秒止まったとき、または編集が続いていても30秒ごとに記録します。残ったバックアップは既定で7日間保持します。

自動バックアップは上書き保存とは別です元の文書ファイルは、Ctrl+S などで保存するまで更新されません。一度も保存していない新規文書は自動バックアップの対象にならないので、書き始めたら早めに名前を付けて保存してください。

異常終了の後に復元する

  1. 編集していた文書を開きます。バックアップが残っていれば［前回保存されなかった変更があります］と表示されます。
  2. 日時を確認して［復元］を選ぶと、バックアップの内容が編集画面に戻ります。［破棄］を選ぶとバックアップは削除されます。
  3. 復元した内容を確認し、Ctrl+S で保存します。復元しただけでは元ファイルは変わりません。

14困ったときは

書式のボタンが灰色で押せません

太字などは文字を選んでから押します。また、表の中など、今の場所では使えない操作もあります。ソース表示中の場合は通常表示に戻して確認してください。

画像が表示されません

文書と一緒に画像フォルダを移動したか、参照先の画像ファイルが残っているかを確認してください。URL参照の場合は接続状況と［外部（https）の画像を表示する］の設定を確認します。必要なら画像を右クリックして差し替えます。

文字化けしています

［ファイル］→［文字コードを指定して開き直す］で、作成元の文字コードを選びます。正しく表示されることを確認してから保存してください。

書式を付けずに貼り付けたいです

Ctrl+Shift+V を使います。WordやWebからの変換を行わず、文字だけを貼り付けます。

終了前の内容が保存されていません

自動バックアップは自動保存ではありません。文書を開き直して復元の確認が出るかを確認します。一度も保存していない新規文書はバックアップ対象外です。普段の保存には Ctrl+S を使ってください。
